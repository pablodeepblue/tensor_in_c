# Tensor in C
This is both a personal exercise and a general tool to teach people about tensors, neural nets, and transformers.
The goal is to go from python with no external lib and slowly implement everything with a lower level language such as c to improve speed.
With exception of comments for tutorials and most documentation, everything will be done free of LLM's. This is both a tutorial and a exercise for me.
